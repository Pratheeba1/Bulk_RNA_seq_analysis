# Data Description

Bulk RNA sequencing was performed using HEK293T cells treated with
lipid nanoparticle formulations containing TriLink eGFP mRNA.

The experimental conditions analyzed were:

| Condition | Description |
|---|---|
| Untreated | Untreated HEK293T cells used as control |
| BNT | BioNTech reference LNP formulation |
| TriB35/mRNA 1:1 | TriB35-to-mRNA ratio of 1:1 |
| TriB35/mRNA 3:1 | TriB35-to-mRNA ratio of 3:1 |
| TriB35/mRNA 10:1 | TriB35-to-mRNA ratio of 10:1 |

Each condition was analyzed using biological replicates.

The sample-to-condition assignments used for differential expression
analysis are provided in the repository metadata.
