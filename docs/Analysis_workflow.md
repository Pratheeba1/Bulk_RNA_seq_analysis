# Bulk RNA-seq Analysis Workflow

The bulk RNA-seq data were processed using the following workflow:

FASTQ files
↓
Quality control and read preprocessing
↓
Salmon transcript quantification
↓
tximport
↓
DESeq2
↓
Differential gene expression analysis
↓
Gene annotation
↓
Visualization
↓
GO and KEGG pathway enrichment

## Differential expression analysis

Transcript-level abundance estimates generated by Salmon were imported
into R using tximport and analyzed using DESeq2.

The following treatment-versus-control comparisons were performed:

- BNT vs untreated control
- TriB35/mRNA 1:1 vs untreated control
- TriB35/mRNA 3:1 vs untreated control
- TriB35/mRNA 10:1 vs untreated control

Genes with an adjusted p-value (padj) < 0.05 were considered
statistically significant.

Differential expression results were subsequently used for visualization,
gene annotation, and functional enrichment analysis.
